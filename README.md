# SMART-CRIME-HEADLINE-DETECTION

## Overview
Smart Crime Headline Detection is a Machine Learning and Natural Language Processing (NLP) web application that classifies news headlines as *Crime* or *Non-Crime*. The application uses TF-IDF vectorization for text preprocessing and a trained machine learning model for prediction. The project is deployed using Streamlit.

## Features
- Detects whether a news headline is crime-related.
- User-friendly Streamlit interface.
- Fast and accurate predictions.
- Built using Machine Learning and NLP techniques.

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Joblib
- TF-IDF Vectorizer

## Installation

Clone the repository:

bash
git clone https://github.com/Saipraneethkanapaka/SMART-CRIME-HEADLINE-DETECTION.git


Install the required packages:

bash
pip install -r requirements.txt


Run the application:

bash
streamlit run https://smart-crime-detection.streamlit.app/
